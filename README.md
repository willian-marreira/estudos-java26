# 📚 Java & Algorithms Studies

This repository contains my exercises and small projects developed during my Java studies, focusing on fundamentals, object-oriented programming, and programming logic.

## 🛠️ Technologies & Tools

* **Language:** Java 26
* **IDE:** IntelliJ IDEA
* **Version Control:** Git & GitHub

## 📂 Repository Structure

The code is organized into thematic packages within the src directory, including fundamentals, conditional structures, repetition structures, and object-oriented programming examples.

## 🚀 How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Navigate to the desired class with the main method to execute the application.
